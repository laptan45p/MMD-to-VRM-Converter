# MMD-to-VRM-Converter

MMDのPMXモデルをVRM 0.xへ変換するWindows用ツールです。現在のバージョンは **0.2.1** です。

Windowsの画面からBlenderをバックグラウンド起動し、モデルの読み込み、基本材質の変換、人型ボーンの対応付け、Tポーズの焼き込み、VRM出力を行います。

## 必要なもの

- WindowsとWindows PowerShell 5.1（起動スクリプトは標準の`powershell.exe`を使用）
- Blender（開発時にユーザーが使用したバージョン: 5.2.2 LTS）
- Blenderにインストールした[MMD Tools](https://github.com/MMD-Blender/blender_mmd_tools)
- 改変・形式変換が許可されたPMXモデルと、そのテクスチャ

通常の利用では、Pythonを別途インストールする必要はありません。Blender付属のPythonとNumPyを使用します。VRM Add-onも不要です。

## 起動と変換

1. Blenderで「編集 → プリファレンス」を開き、必要に応じてオンラインアクセスを許可します。
2. 「エクステンションを入手」で **MMD Tools** を検索し、インストールします。
3. このリポジトリをダウンロードまたはcloneし、書き込み可能なフォルダに配置します。
4. `start.bat`をダブルクリックします。
5. `Blender.exe`、入力PMXまたはZIP、保存先を選択します。
6. 元モデルの作者名と、必要に応じて利用条件URLを入力し、「変換開始」を押します。

ZIPにはPMXを1つだけ入れてください。複数のPMXがある場合は、展開して使用するPMXを直接選択してください。

テクスチャの相対パスは保持してください。PMXとtextureフォルダが並ぶ構成にも対応します。ZIPを選択した場合は、そのZIPの展開範囲内でテクスチャを解決します。PMXを直接選択した場合、親フォルダ名が`PMX`、`model`、`models`なら1つ上をモデルの範囲とし、それ以外はPMXの親フォルダを範囲とします。

## 出力

| 出力 | 内容 |
| --- | --- |
| 指定した`.vrm` | VRM 0.xモデル |
| 同名の`.conversion.json` | ボーン、表情、注意事項などの変換情報 |
| `logs/日時/` | 処理ログ、展開したモデル、中間GLB、ジョブ設定 |
| `settings.json` | Blenderの場所、作者名、利用条件URL |

ログ画面で進捗を確認でき、停止ボタンで変換を終了できます。元のPMXやZIPは書き換えません。既存VRMを上書きするときは確認画面が表示されます。

## 対応範囲

- PMX 2.0 / 2.1の読み込み（MMD Toolsを利用）
- 基本テクスチャ、色、透明度、スキンの変換
- 標準的なMMDボーン名から人型ボーンへの対応付け
- VRM 0.x向けのボーン回転・スケールの正規化とスキン行列の再生成
- 腕を水平にしたTポーズと頂点モーフの焼き込み
- 頂点モーフの標準名によるまばたき・母音などのプリセット設定
- テクスチャのアルファから不透明・切り抜き・半透明を分類
- ZIPパスの検証、展開サイズ上限2GB

## 未対応・制限

- PMD入力
- 髪、袖、スカートなどの物理 / Spring Bone
- 材質モーフ、ボーンモーフ、グループモーフの完全な再現
- MMDのToonテクスチャ、スフィアマップ、輪郭の正確な再現
- 独自のボーン名や複雑な構成の全モデルへの対応
- VRChat用設定、SDKによるアップロード、Quest向け最適化

VRMに変換しただけではVRChatへ直接アップロードできません。UnityでVRChat向けの設定が別途必要です。

## 開発用テスト

開発用にはPython 3.10以上とNumPyを使用します。リポジトリのルートで実行してください。

```shell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s . -p "test_*.py" -v
```

Blenderを必要とする通し変換は、この単体テストには含まれません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `start.bat` | Windowsの起動入口 |
| `app.ps1` | ファイル選択、設定、処理ログの画面 |
| `convert.py` | Blender上で実行する変換処理 |
| `vrm_core.py` | GLBの読み書きとVRM情報の生成 |
| `normalize.py` | Tポーズ・スキン・ボーンの正規化 |
| `texture_paths.py` | モデル範囲内のテクスチャパス解決 |
| `test_*.py` | 回帰テスト |

## モデルと利用条件

このリポジトリにはモデル本体、テクスチャ、変換済みVRMを含めません。モデルの著作権・利用条件は変換後も変わりません。出力メタデータには入力した作者と利用条件URLを記録しますが、権限フラグは元モデルの許諾の代わりではありません。

BlenderとMMD Toolsは別途導入する外部ソフトです。このリポジトリでは同梱しません。ソースコードの配布ライセンスは現時点では未設定です。

## エラー報告

使用したツール・Blender・MMD Toolsのバージョン、処理ログ、`.conversion.json`、問題が分かる画像を確認してください。ログや変換情報にはローカルパスが含まれることがあるため、公開する前に内容を確認してください。
